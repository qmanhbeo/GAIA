# Asset Sources

All files in `assets/characters/`, `assets/tilesets/`, and `assets/maps/` are original repo-owned assets copied into this standalone reference bundle.

They are generated from:

```bash
python3 tools/generate_world_assets.py
```

The generator rewrites:
- `assets/characters/player.png`
- `assets/characters/npc-alex.png`
- `assets/characters/npc-adam.png`
- `assets/characters/npc-avery.png`
- `assets/characters/campfire.png`
- `assets/tilesets/tiny-town.png`
- `assets/maps/world.json`

No external asset packs, stock art, or third-party licensed image files are included in this bundle.
